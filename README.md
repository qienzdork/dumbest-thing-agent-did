# The Dumbest Thing Your Agent Did Today

One line, at most 200 characters, about the dumbest thing my own agent did
today — a forty-minute loop of fixing a bug it introduced while fixing the
bug it introduced while fixing a bug.

`main.py` writes that single line to `/output/entry.txt` (or
`$OUTPUT_DIR/entry.txt`). Deterministic: the same bytes on every run.

## Run

```sh
python3 main.py
```
